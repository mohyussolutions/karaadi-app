# Demo media

Drop the demo video files in this folder using these exact filenames so they show up
automatically in `src/docs/README.md`:

- `karaadi-app-part-1.mp4` — Part 1: Overview
- `karaadi-app-part-2.mp4` — Part 2: Core features
- `karaadi-app-part-3.mp4` — Part 3: Advanced features

Keep files reasonably small (ideally under ~50MB each) so the repo stays lightweight —
consider compressing with `ffmpeg` or hosting larger files elsewhere and linking out
if needed.
